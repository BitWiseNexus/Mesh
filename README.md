# Mesh

Open-source visual builder for multi-agent AI workflows. Drag nodes (triggers, agents, tools,
knowledge, logic, actions) onto a canvas, connect them, and run them with live streaming.

- `frontend/` — Next.js + React Flow canvas
- `backend/` — FastAPI execution engine
- Firebase — Auth, Firestore, Storage, vector search

See [context.md](context.md) for architecture and decisions, and [PLAN.md](PLAN.md) for the build plan.
